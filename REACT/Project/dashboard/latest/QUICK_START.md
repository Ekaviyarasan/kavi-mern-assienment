## 🎯 First Time Setup

### Step 1: Create an Account
- Click "Get Started" on landing page
- Go to `/auth`
- Sign up with email
- Set password
- Verify email (if applicable)

### Step 2: Complete Your Profile
- Go to `Resume` section
- Click "Edit Profile"
- Fill in:
  - Full name
  - Professional headline
  - Email & phone
  - Location
  - Professional summary
- Add work experience
- Add education
- List your skills
- Click "Save Resume"

### Step 3: Add Resume File
- In Resume page, scroll to "Resume File" section
- Click "Upload Resume"
- Select PDF, DOC, or DOCX file
- Done! File is uploaded

## 💡 How to Use Each Feature

### 🔍 Search for Jobs

**Quick Search:**
1. Go to **Marketplace**
2. Type job title in search bar
3. Press Enter
4. Browse results

**Advanced Search:**
1. Go to **Marketplace**
2. Click **Filter** button
3. Choose your filters:
   - Job Type
   - Experience Level
   - Location
   - Salary Range
   - Company
   - Date Posted
4. Click **Apply Filters**
5. Browse filtered results

---

### 📄 Resume Management

**Create/Edit Resume:**
1. Go to **Resume**
2. Click **Edit Profile**
3. Update information
4. Click **Save Resume**

**Add Experience:**
1. In edit mode, scroll to "Experience" section
2. Click **Add Experience**
3. Fill job details
4. Save

**Upload Resume File:**
1. Scroll to "Resume File" section
2. Click **Upload Resume**
3. Select file (PDF/DOC/DOCX)
4. Confirm upload

---

### ✅ Track Applications

**View All Applications:**
1. Go to **Applications**
2. See all your submitted applications
3. Each shows:
   - Job title
   - Company
   - Status (Applied/Interview/Offered/Rejected)
   - Next action

**Filter Applications:**
1. Click filter buttons at top
2. Choose: All / Applied / Interview / Offered / Rejected
3. See filtered results

**Search Applications:**
1. Use search bar
2. Search by job title or company name
3. Results update automatically

**Message Recruiter:**
1. Find application
2. Click **Message** button
3. Type your message
4. Send

---

### ➕ Post a Job (For Employers)

**Step 1: Basic Info**
1. Click **Post Job** in sidebar
2. Enter:
   - Job title
   - Company name
   - Location
   - Job type
   - Experience level
   - Category
3. Click **Next Step**

**Step 2: Job Details**
1. Write job description
2. Set salary range
3. Enter minimum salary
4. Enter maximum salary
5. Add required skills
6. Add benefits
7. Set application deadline
8. Click **Review & Publish**

**Step 3: Review**
1. Check all information
2. Make corrections if needed
3. Click **Publish Job**

**Step 4: Done!**
- Job is live
- Candidates can see it in marketplace
- You can track applications

## 🎯 Quick Tips

### For Job Seekers:
✅ **Do:**
- Complete your entire profile (100%)
- Upload a professional resume
- Use specific keywords in searches
- Apply within 24 hours of posting
- Respond to recruiter messages quickly
- Track all applications
- Follow up on pending applications

❌ **Don't:**
- Leave profile incomplete
- Apply to jobs you're not qualified for
- Send generic cover letters
- Ignore recruiter messages
- Apply to same job multiple times
- Use unprofessional resume

### For Employers:
✅ **Do:**
- Write clear job descriptions
- List all requirements
- Set competitive salary
- Respond to applications promptly
- Provide feedback to candidates
- Use specific keywords

❌ **Don't:**
- Post vague job descriptions
- Hide salary information
- Ignore applications for weeks
- Post duplicate jobs

## 🆘 Troubleshooting

### Problem: Resume not uploading
**Solution:**
- Check file size (max 5MB)
- Ensure file is PDF, DOC, or DOCX
- Try different file
- Refresh page and try again

### Problem: Can't find jobs
**Solution:**
- Clear search filters
- Try different keywords
- Check location setting
- Search by company name instead

### Problem: Application not submitted
**Solution:**
- Check internet connection
- Ensure profile is complete
- Try again
- Contact support

### Problem: Message not sending
**Solution:**
- Check internet connection
- Refresh page
- Try sending again
- Ensure recruiter exists

### Problem: Page loading slowly
**Solution:**
- Clear browser cache
- Close other tabs
- Refresh page
- Try different browser

### Problem: Can't log in
**Solution:**
- Check email address
- Reset password
- Clear browser cache
- Try different browser
